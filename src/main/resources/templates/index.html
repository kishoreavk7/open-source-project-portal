📖 Project Introduction

The Open Source Project Portal is an enterprise-pattern DevOps demonstration project. It features a full-stack Spring Boot web application that connects with the GitHub REST API to dynamically retrieve repository health and engagement telemetry. The application lifecycle is managed entirely through automated Continuous Integration (Jenkins), Infrastructure as Code (Terraform), Configuration Management (Ansible), and Container Orchestration (Kubernetes).

💻 Installation Guide (Local VS Code)

Follow these beginner-friendly steps to clone, package, test, and run the portal on Windows or macOS/Linux.

Windows (PowerShell / Command Prompt)
# 1. Clone the repository
git clone https://github.com/kishoreavk7/open-source-project-portal.git
cd open-source-project-portal

# 2. Compile and package the application
.\mvnw.cmd clean package

# 3. Execute unit and integration tests
.\mvnw.cmd test

# 4. Launch the application locally
.\mvnw.cmd spring-boot:run
Linux / macOS
# Make wrapper executable and run
chmod +x mvnw
./mvnw clean package
./mvnw test
./mvnw spring-boot:run

Access the running portal in your browser: http://localhost:8080

🐳 Docker Container Instructions

The portal is packaged using an optimized multi-stage Docker build with an unprivileged runtime user.

Docker CLI
# 1. Build the lightweight Docker image
docker build -t open-source-project-portal .

# 2. Run container in background on port 8080
docker run -d -p 8080:8080 --name portal open-source-project-portal

# 3. View container logs
docker logs -f portal
Docker Compose (1-Command Run)
docker-compose up -d --build

🚀 Complete DevOps CI/CD Architecture

The automated end-to-end delivery pipeline orchestrating every code commit to cloud deployment:

1
Developer & Git Branching Code authored on feature/github-metrics → PR to develop → Release to main
2
GitHub & Webhook Trigger Git Push triggers Jenkins build job via SCM polling or webhook endpoint
3
Jenkins CI & Maven Build Declarative Jenkinsfile executes Maven compilation, unit tests, and JAR packaging
4
Docker Build & Container Registry Containerized image built and pushed securely to Docker Hub registry with version tags
5
Terraform Infrastructure as Code Provisions AWS VPC, subnets, route tables, security groups, and EKS/EC2 cluster
6
Ansible Configuration Management Configures server environments, installs containerd/docker, applies kernel parameters
7
Kubernetes Orchestration & Ingress Zero-downtime rolling updates, Actuator health probes, self-healing, HPA autoscaling
